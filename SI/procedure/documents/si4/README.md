# SI4 procedures

The procedures are organized around the requested computational substrate
scope materials:

1. `data-generation.md` — curated records, feature data, progressive routes,
   GenAI candidate generation, deterministic controls, and screening.
2. `progressive-learning.md` — sequential reveal, model fitting, controls,
   audits, and convergence metrics.
3. `guarded-transfer.md` — reciprocal transfer and negative-transfer guards.
4. `checkpoint-10.md` — the 0–100 development-map score and correct use.
5. `claim-boundary.md` — what the retrospective computational evidence does
   and does not establish.

The original source documents used to assemble the feature and expansion work
are retained under `source-docs/docs/`.

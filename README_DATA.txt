PULSE-Cat computational records

The curated-datasets directory contains the source-audited reaction ledgers and membership information referred to in the SI. These files were assembled before the nitrene-index correction and should be used for source-record and outcome provenance, not as authoritative corrected pose features. The records/corrected_project directory contains corrected pose inputs, results and scripts; records also include intermediate and historical analyses for provenance. The original historical run tree does not establish exact bitwise reproduction of every prior pose-derived result. Scripts may require workspace-specific paths, dependencies, or source files; full independent reproduction has not been verified. No public repository deposit or DOI is represented by this archive.

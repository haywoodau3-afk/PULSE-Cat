## Pair and descriptor commitments before coefficient inspection

The source Table 1 identifies 1a/2a (92% ee) and 1ah/2ah (50% ee), both using Fe(P7)Cl under its 60 °C standard conditions. Both have the same aryl azide and initial two-carbon tether; the carbon that becomes stereogenic is attached to phenyl in 1a versus ethyl in 1ah. This is an interpretable substituent contrast but also changes electronic and conformational properties, so no isolated steric causal claim is justified. Compared with the candidate 1aj (44% ee, 80 °C), this pair avoids a reported temperature change. Lowest-scoring retained UFF pose, rank 1, is the prespecified illustration for each.

Before inspecting model coefficients, we will trace two intuitively defined, archived pose-interaction features: mean substrate-heavy-atom centroid-to-Fe distance and mean nitrene-N-to-reported-reactive-carbon distance across all 200 retained poses. Both are input features in the 1,241-field structure-plus-pose benchmark, but centroid distance changes with molecular size and atom count, and neither is a barrier, mechanistic energy or direct isolated steric parameter. We will check the fitted coefficient and reconstruct each held-out prediction before making any claim about use. The 38-record benchmark source uses a global, label-blind zero-variance feature screen before held-out splits; training-fold scaling is fitted separately. This is transductive feature screening, so earlier blanket wording that all feature removal was training-only must be qualified after verifying the implementation.

## Source-code issue discovered during direct geometry verification

Direct recalculation of the preselected N-to-reactive-carbon descriptor agrees for 1a but not for 1ah: the archived mean for 1ah is 2.53855 Å, while the actual nitrene-N-to-carbon mean from the same 200 XYZ files is 3.58151 Å. The archived `stage2_pose_interaction.py` and `stage2p_representation.py` use molecule index 0 as the nitrene, despite the assembly explicitly reordering the actual nitrene to first position; for suffix-style nitrene SMILES, molecule atom 0 is carbon. The hydrogen-selection helper shares the same assumption, as does stage2pp through its use of stage2p, and `stage3a_reference_features.py` contains a similar assumption. This affects the validity of prior features and potentially the prior representation and acquisition comparisons; do not claim it only affects the illustrative pair or that earlier results are unaffected. A preliminary structural check finds index 0 is not nitrene for 12/38 active P7 and 14/26 active CMC records; those counts identify at-risk structures, not independent proof that every exported field was affected.

Before making scientific edits, independently validate the atom identity and quantify the affected fields and analyses; implement and test corrected atom mapping in revision-local code, preserve the original archive, and determine which prior results can be recomputed consistently. If correction and full revalidation cannot be completed, mark the earlier manuscript and release package as provisional rather than presenting the earlier results or descriptors as reliable. This issue was discovered after the original plan and is a necessary expansion, not a preplanned result.

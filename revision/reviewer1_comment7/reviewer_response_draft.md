# Draft response to Reviewer 1, comment 7

We thank the reviewer for identifying the narrow set of acquisition comparators. We have added retrospective benchmarks against a query-by-committee strategy, expected improvement and Thompson sampling. The committee selects the greatest disagreement among Ridge, Elastic Net and Tanimoto-kNN predictions; the two optimisation strategies use the same fixed Gaussian-process surrogate on Morgan/Tanimoto fingerprints. Their selection objectives and model choices are described in the SI. We used the same 20 overlapping common-test splits, starting pairs, candidate pools and label budgets as the existing common-test analysis, and scored all selected datasets with the same held-out Ridge predictor. Random and Thompson sampling results each average three seeded continuations per start.

Mean held-out ee MAEs for PULSE / query by committee / expected improvement / Thompson sampling were 13.88 / 13.22 / 13.56 / 14.27 ee points for Fe(P7)Cl and 14.27 / 13.99 / 15.15 / 15.65 for Fe(CMC-Por)Cl aryl substrates. Query by committee gave lower average error than PULSE in both datasets; expected improvement also did so for Fe(P7)Cl. Results varied across splits, and we have removed any implication that PULSE is superior to established active-learning methods. The committee shares a disagreement component with PULSE, and these comparisons concern one implementation and parameterisation of each method on two small, retrospective datasets.

Expected improvement and Thompson sampling target high |ee| rather than scope-wide prediction, so the revised SI also reports the best observed |ee| at each budget. At six labelled substrates, mean best |ee| for PULSE / query by committee / expected improvement / Thompson sampling was 93.53 / 93.48 / 93.38 / 93.65% for Fe(P7)Cl and 84.92 / 86.72 / 85.37 / 86.73% for Fe(CMC-Por)Cl. Neither metric establishes a general state-of-the-art ranking; broader independent and prospective studies with additional optimised baselines are required.

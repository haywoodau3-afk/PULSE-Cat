## Definitions and sources

- Query by committee (QBC) selects the candidate with greatest disagreement among multiple models. Use the existing Ridge, Elastic Net and Tanimoto-kNN committee, standard deviation of their clipped ee predictions, without the novelty and family terms. It shares the same committee disagreement component as the existing rule, so is a targeted ablation and a recognisable heterogeneous regression committee—not an independent implementation of every QBC variant. See Burbidge et al., *Active Learning for Regression Based on Query by Committee* (2007), https://dl.ifip.org/db/conf/ideal/ideal2007/BurbidgeRK07.pdf.
- Expected improvement (EI) chooses the candidate with largest Gaussian-process expected improvement over the best observed ee. Thompson sampling (TS) maximises one correlated joint draw from that GP posterior over the candidate pool; repeat three seeded draws per starting pair. Both are outcome optimisation strategies, and mean held-out MAE is not their own objective. Bayesian optimisation background: Frazier, *A Tutorial on Bayesian Optimization*, https://arxiv.org/abs/1807.02811; joint posterior sampling: https://arxiv.org/abs/1604.00169.
- Both BO rules use the same prespecified, outcome-standardised Gaussian process with a fixed Tanimoto kernel on Morgan fingerprints, kernel diagonal noise 0.05, no hyperparameter search and zero prior mean on the standardised scale. Refit on revealed ee labels only. Use latent posterior covariance for TS, with tiny diagonal numerical jitter; standard deviation for EI is latent. Use normal EI with zero exploration offset and the best observed ee incumbent. If the revealed label standard deviation is zero, use scale 1 ee point. These fixed settings form one baseline implementation, not an exhaustive assessment of BO methods or tuning.
